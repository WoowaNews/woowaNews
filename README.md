# 📰 우아한 뉴스

> 층과 교육 분야의 경계를 넘어, 오늘의 인사가 내일의 연결이 되는 우테코 데일리 신문 웹앱

우아한 뉴스는 우아한테크코스 크루들이 서로를 더 자연스럽게 발견하고,
가볍게 대화를 시작할 수 있도록 돕는 데일리 신문 형식의 커뮤니티 웹앱입니다.

같은 층, 같은 트랙 중심으로 생활하다 보면 다른 크루를 알거나 먼저 말을 걸 기회가 생각보다 많지 않습니다.
우아한 뉴스는 매일 발행되는 신문처럼 크루, 생일, 미션 활동, 점심 투표, 마을별 소식을 한곳에 담아
작은 인사가 실제 연결로 이어지도록 돕습니다.

## 🎯 프로젝트 대상

우아한 뉴스는 다음과 같은 사람들을 위해 만들어졌습니다.

- 우아한테크코스 8기 크루
- 다른 층, 다른 트랙 크루들의 활동과 분위기를 알고 싶은 사람
- 더 자연스럽게 대화와 교류를 시작하고 싶은 사람
- 우테코 생활 속 소속감과 연결감을 높이고 싶은 사람

## 💡 문제의식

우테코에서는 같은 층, 같은 교육 분야의 크루들과 주로 생활하게 됩니다.
그러다 보니 다른 층이나 다른 트랙의 크루를 알게 되는 기회가 제한적이고,
먼저 말을 걸 수 있는 자연스러운 계기도 많지 않았습니다.

저희는 이 문제를 단순히 정보를 모아 보여주는 방식이 아니라,
**대화를 시작할 이유를 만들어주는 서비스**로 풀고자 했습니다.

우아한 뉴스는 다음과 같은 문제에 집중합니다.

- 서로를 알 기회가 부족한 문제
- 대화의 시작점이 적은 문제
- 층과 트랙 간 교류가 자연스럽게 일어나기 어려운 문제

## 🗞️ 서비스 소개

우아한 뉴스는 매일 발행되는 신문 형식으로 우테코의 다양한 소식을 전달합니다.

- 오늘의 크루를 통해 새로운 크루를 발견합니다.
- 생일 크루를 소개해 축하 인사를 건넬 계기를 만듭니다.
- 마을별 소식과 코치의 한마디로 우테코 안의 분위기를 공유합니다.
- 미션 발자국을 통해 GitHub 기반 활동을 재미있게 돌아봅니다.
- 점심 메뉴 투표로 가볍게 참여할 수 있는 커뮤니티 경험을 제공합니다.

이를 통해 “오늘 이 사람한테 인사해볼까?”,
“생일인 크루에게 축하 한마디 해볼까?” 같은 작은 행동이 실제 교류로 이어지도록 설계했습니다.

초기 버전에서는 해커톤 구현 범위에 맞춰 일부 콘텐츠를 사전 구성된 데이터로 제공합니다.
이후에는 크루들의 직접 제보와 활동 데이터를 연계하여,
실시간으로 함께 만들어가는 우테코 신문으로 확장하는 것을 목표로 합니다.

## ✨ 주요 기능

### ⭐ 오늘의 크루

- 매일 한 명의 크루 소개
- 다른 층 크루를 자연스럽게 발견
- “오늘은 이 크루에게 먼저 인사해보세요!” 같은 가벼운 교류 계기 제공

### 🎂 이달의 생일 크루

- 생일인 크루를 신문에 소개
- 축하 메시지를 전할 수 있는 자연스러운 연결 포인트 제공

### 👣 이번 미션 발자국

- GitHub 데이터를 기반으로 미션 활동 집계
- PR, Commit, Comment 통계 제공
- 첫 PR, 첫 머지, 최다 커밋 등 랭킹 제공

### 🍱 점뭐먹 투표

- 오늘 점심 선택 투표
- 주말에는 밸런스 게임 진행

### 📋 교육 트랙별 미션 현황

- 백엔드, 프론트엔드, 안드로이드 미션 진행 상황 표시

### 🏘️ 커뮤니티 콘텐츠

- 층별, 마을별 분위기와 소식 공유
- 코치의 한마디 제공
- 향후 크루들의 제보 기반 소식 등록 및 참여형 콘텐츠 확장 예정

## 🚀 서비스 강점

### 1. 정보를 보여주는 것이 아니라 대화를 시작하게 합니다

오늘의 크루, 생일 크루처럼 다른 크루에게 먼저 말을 걸 수 있는 이유를 제공합니다.
단순한 조회 경험을 넘어 실제 오프라인 교류로 이어질 수 있는 계기를 만듭니다.

### 2. 우테코 안에서만 가능한 연결 경험을 제공합니다

GitHub 활동, 크루 정보, 마을 문화를 하나의 신문으로 묶어
다른 층과 트랙의 크루들을 자연스럽게 이어줍니다.

### 3. 부담 없이 참여할 수 있습니다

좋아요, 점심 투표, 생일 축하처럼 가벼운 행동만으로도 커뮤니티에 참여할 수 있습니다.
참여의 부담은 낮추고, 연결의 가능성은 높였습니다.

### 4. 매일 새로운 사람과 소식을 발견합니다

날짜 기반 콘텐츠를 통해 매일 다른 크루 소개와 새로운 우테코 내부 소식을 접할 수 있습니다.
반복 방문할 이유가 있는 데일리 커뮤니티 경험을 제공합니다.

## 🌱 앞으로의 확장 방향

- 크루 직접 제보 기반 소식 등록
- 실시간 GitHub 활동 데이터 연동
- 생일 축하 메시지와 응원 메시지 기능 확장
- 층별, 트랙별, 마을별 참여형 콘텐츠 강화
- 매일 발행되는 우테코 신문 경험 고도화
